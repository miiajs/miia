# create-miia

Creates a [MiiaJS](https://miiajs.com) app. Runs `miia new` from [`@miiajs/cli`](https://www.npmjs.com/package/@miiajs/cli) with the same flags.

```bash
bun create miia my-app
npm create miia@latest my-app
deno run -A npm:create-miia my-app
```

Flags: `--runtime`, `--pm`, `--features`, `--db`, `-y`, `--skip-install`, `--dry-run`.
