# @miiajs/multipart

Streaming `multipart/form-data` for MiiaJS - `@Multipart` with a backpressured part iterator, per-file and per-form limits, buffered `ctx.form()`, and `@ValidateForm`.

## Installation

```bash
npm install @miiajs/multipart
```
